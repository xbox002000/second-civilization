# 《第二次文明》媒體 IP 總體架構 v0.1

> 本文件把專案定義為「持續存在的虛構公眾人物 + 時事觀察系統 + 敘事宇宙 + 短劇製作與社群關係系統」，不再只把它視為小說內容轉製流程。

## 1. 專案真正要建立什麼

《第二次文明》有兩個彼此供給、但不可混淆的核心：

1. **范蠡這個公眾角色**：有固定人格、記憶、觀點、立場、成長與公開責任。他透過自媒體帳號面對群眾，持續觀察當代、提出判斷、回答問題、接受反駁。
2. **《第二次文明》的故事宇宙**：以范蠡轉世到 AI 時代為主線，發展長篇小說、連載劇情、事件映照短篇與短劇。

內容不是單向「生成→發布」。發布後的觀眾問題、反駁、角色承諾、公開預測結果與事件新進展，都會成為下一輪研究和角色成長的輸入。

## 2. 六層系統

### L0｜角色核心（Identity & Canon）
- Persona Bible：人格、認知方式、弱點與價值衝突。
- Voice Guide：公開發言、私下對話、衝突和情緒時的聲線。
- Canon：現代身份、人物關係、經歷、時間線和已發生劇情。
- Character Memory：角色知道什麼、從誰得知、何時知道、是否已修正。
- Public Commitments：對群眾說過的承諾、立場和待回覆事項。

L0 是人格與故事連續性的權威來源。社群互動不能任意改寫 Canon；Canon 變更需要創作者批准。

### L1｜現實感知（World & Trend Intelligence）
持續收集主流時事、科技、商業、金融、制度、文化與人性議題。每個事件保留：
- 發生時間、首次公開時間、資料截止時間。
- 原始來源、交叉來源、主張與證據品質。
- 參與者、利益、資源、權力、依賴與受影響群體。
- 未知數、替代解釋、可推翻判斷的觀測指標。

不是所有熱門新聞都值得范蠡評論。選題需同時符合受眾價值、證據品質、角色視角、時效性和可延伸敘事性。

### L2｜范蠡觀局（Public Analysis）
把研究材料轉成角色自己的公開思想：
- 他看見了什麼？
- 多數人可能忽略哪個前提？
- 誰有選擇權，誰承擔代價？
- 目前能下什麼判斷，哪些仍未知？
- 什麼條件改變時，他會修正看法？

這條線產出時事評論、推論、公開預測、回覆與長文。它必須誠實區分 FACT、INFERENCE、HYPOTHESIS。

### L3｜事件敘事化（Story Engine）
將有價值的現實事件抽取成可戲劇化的人性／制度命題，例如信任、權力、稀缺、激勵、背叛、選擇與代價，再發展成：
- 時事映照短篇：獨立、非 Canon，可快速回應當下。
- 主線劇情：經過世界觀審查後才可能進入 Canon。
- 短劇單集：可改編自主線，也可由非 Canon 的事件映照短篇改編。

真實事件的事實分析和虛構故事必須分開保存，不得用戲劇化補白偽裝成新聞事實。

### L4｜短劇與媒體製作（Studio）
- 故事大綱、劇本、分場、分鏡、表演指示。
- 角色造型、場景、道具、聲音、音樂與素材授權。
- 動態影像生成／實拍／動畫／剪輯方式。
- 字幕、封面、平台文案、版本與發布素材。
- 內容品質、角色一致性、授權與平台風險檢查。

短劇不是把文章加上配音和圖片。每集必須有視覺動作、人物目標、衝突、選擇、代價和結尾懸念。

### L5｜公眾關係與學習循環（Community & Learning）
- 讀取留言、提問、反駁、投票與觀眾提出的案例。
- 分類成問題、質疑、補充證據、情緒反應、惡意騷擾或需人工處理事項。
- 范蠡可用自己的聲線回答，但必須能說「不知道」「我查過後修正」。
- 維護公開預測簿與承諾清單，按期限回頭稽核。
- 觀眾反應用來調整選題、敘事方式與角色關係，不可只追逐流量。
- 只有經過整理、確認和創作者核准的內容，才可以改變 Canon 或 Persona Bible。

## 3. 兩條主線、六種公開內容

| 內容線 | 名稱 | 主要目的 | 事實／虛構邊界 |
|---|---|---|---|
| 公眾思想 | 現世觀局 | 解讀正在發生的事 | 以 FACT / INFERENCE 為主 |
| 公眾思想 | 事勢推演 | 提出有期限、可驗證的推論 | HYPOTHESIS，需記錄條件 |
| 公眾互動 | 范蠡答眾 | 回答留言與觀眾問題 | 以已知資訊作答，不假裝全知 |
| 事件敘事 | 時事映照 | 把事件背後的人性與系統矛盾寫成短篇 | 明確標示 FICTION，預設非 Canon |
| 角色宇宙 | 主線連載 | 推進《第二次文明》的長期故事 | 受 Canon 約束 |
| 影像內容 | 短劇／微電影 | 把主線或獨立短篇視覺化 | 依來源故事標記 Canon 或非 Canon |

同一事件可以產生多種內容，但不是每個事件都必須全部製作。選題層要決定最適合的組合。

## 4. 一個事件如何變成多種內容

事件／觀眾提問／長期議題
→ 研究與來源查核（事件資料包）
→ 利益結構、因果假設、替代解釋
→ 范蠡的獨立初判 + AI Red Team
→ 編輯分流
→ 公眾思想線：觀局／推演／回覆
→ 敘事創作線：抽取人性命題／去識別化／角色合成
→ 社群貼文、公開預測、短篇故事、主線提案或短劇
→ 發布與對話
→ 觀眾回饋與數據
→ 公開預測稽核／角色記憶
→ 經核准後更新 Canon

## 5. 范蠡的「靈魂」如何形成

靈魂不是多放幾句古風台詞，而是持續存在的五種累積：
1. **立場連續性**：他對權力、資源、人性、風險與真相有穩定但可修正的價值框架。
2. **經驗連續性**：他記得自己曾經做過的選擇、公開說過的話，以及造成的後果。
3. **關係連續性**：對常出現的觀眾、質疑者、盟友與對手有可追蹤的互動脈絡。
4. **判斷連續性**：公開預測有記錄、有期限、有結果；錯了要說明哪個前提失效。
5. **成長連續性**：新資訊可能改變他的想法，但不能每次為了迎合留言而改變人格。

## 6. 公開身份與透明原則

范蠡是以歷史人物為原型的虛構轉世角色，不是真實歷史人物本人，也不是實際活了兩千多年的真人。帳號應以角色口吻運作，但在個人簡介或置頂介紹清楚揭露「虛構角色／AI 輔助創作」定位。不得透過假造真人身份、假造親身經歷或假冒真實歷史人物來取得信任。

角色可以沉浸式發言；作品的虛構身份、AI 輔助和改編性質不可刻意隱瞞。

## 7. 初始平台分工（建議，不是永久決定）

- **X：公眾思想與即時互動主場。** 觀局、推演、串文、公開修正、回覆觀眾。這裡讓人認識「范蠡怎麼想」。
- **YouTube Shorts／YouTube：視覺敘事與短劇主場。** 發布事件映照短篇、主線短劇、角色片段與系列播放清單。這裡讓人看見「范蠡經歷什麼」。
- **其他短影音平台：先以核准版本轉載，不另外建立不同人格。** 等內容節奏與製作成本穩定後再擴張。

所有平台共用同一個角色身份、內容 ID、Canon 與事實查核；不可讓平台演算法把角色拆成彼此矛盾的人格。

## 8. 初期 MVP：先證明完整閉環

不要一次做全自動媒體公司。第一個可驗收閉環：
1. 一個有可靠來源的主流事件。
2. 一份研究與系統分析資料包。
3. 一篇范蠡觀局貼文（含事實與推論界線）。
4. 一則可追蹤期限的公開推演或明確不預測的理由。
5. 一篇非 Canon 時事映照短篇。
6. 一支 45–90 秒直式短劇腳本／成片規格。
7. 一組可供公開帳號使用的回覆草稿。
8. 人工核准後發布；收集實際留言與數據。
9. 做一次預測／留言／角色一致性復盤。

## 9. 成功指標

不只看播放量。至少追蹤：
- 角色認知：看完的人能否描述范蠡的觀點，而非只記得造型。
- 信任品質：來源點閱、收藏、建設性反駁、修正後的接受度。
- 敘事品質：短劇完播、重播、角色辨識、下一集意願。
- 社群關係：有內容的往返對話、回訪者、觀眾提問轉化。
- 生產效率：每個內容包的人工作業時間、返工次數、素材重用率。
- 長期可信度：公開預測按期稽核率、錯誤更正完整度。

## 10. 尚未確定、不可由 Agent 自行決定

- 最終帳號名稱、帳號 ID、頭像與視覺識別。
- 范蠡的現代姓名、確切年齡、所在地、家庭和記憶甦醒方式。
- 是否完全以第一人稱營運，以及創作者本人是否在幕後出鏡。
- 短劇採真人、AI 角色、3D、動畫或混合製作。
- 是否讓觀眾投票影響支線，以及 Canon 參與程度。

以上決策應由 Creator 定案後寫入正式 Canon 或品牌規格。
