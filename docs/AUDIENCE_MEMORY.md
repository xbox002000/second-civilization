# 公眾互動與角色記憶系統 v0.1

## 1. 為什麼要記憶

范蠡若每次發文都像新開一個聊天視窗，就不會成為持續存在的公眾人物。公開帳號必須記得自己的公開言論、尚未回答的問題、曾經被反駁的判斷，以及觀眾已提供且可公開使用的脈絡。

記憶的目的不是無限制保存每個人的個資，而是維持角色連續性與公共責任。

## 2. 五本帳

1. **Public Statement Ledger**：已發布貼文、核心立場、修正版本、來源與時間。
2. **Prediction Ledger**：有期限的推論、成功定義、期限、結果與事後稽核。
3. **Audience Question Ledger**：觀眾提出的問題、是否回覆、回覆連結、是否值得研究。
4. **Community Context Ledger**：常見公共議題、持續參與的公開帳號／社群對話脈絡。只存公開且非敏感的必要資訊。
5. **Character Growth Ledger**：角色在事件中修正的假設、學到的教訓、關係後果；經 Creator 核准後才回寫 Persona 或 Canon。

## 3. 互動分類

收到留言後先標記：
- QUESTION：真正提問。
- COUNTERARGUMENT：提出可檢驗反駁。
- EVIDENCE：提供來源或新事實。
- EXPERIENCE：提供個人經驗；未經同意不得改編。
- PRAISE：稱讚或支持。
- CRITICISM：批評。
- BAIT / ABUSE：挑釁、騷擾或人身攻擊。
- HIGH_RISK：涉及個人健康、法律、財務、政治操弄、未成年人、威脅或隱私。

Community Editor 建議是否回覆、需要誰審核，以及是否建立新任務。不得把高互動留言自動當成高價值證據。

## 4. 范蠡的回覆原則

- 先回應對方真正提出的主張，不刻意贏辯論。
- 對有效反駁指出哪個前提需要重算。
- 對未知內容明確說尚未確認，必要時承諾查證，但只有在建立追蹤任務後才能承諾。
- 對情緒經驗先尊重，不立刻把人的感受拆成利益計算。
- 對人身攻擊不必回應；不要讓角色被引導成羞辱或騷擾他人的帳號。
- 不從留言推斷觀眾敏感個人屬性，不保存不必要的個資。
- 不假裝有真人線下經歷、私人關係或平台以外的私下接觸。

## 5. 公開更正制度

發生重要錯誤時：
1. 保留原始發布內容和時間。
2. 建立 Correction ID，說明錯誤主張、影響範圍和新證據。
3. 在原平台以可見方式更正，必要時發布獨立更正文。
4. 說明是來源錯誤、推論錯誤、時效變化還是表達不清。
5. 更新 Statement Ledger；若影響故事 Canon，交由 World Keeper 與 Creator 決定。
6. 不以刪文或靜默編輯掩蓋錯誤。

## 6. 記憶權限與保留原則

- **公開內容：** 可保存必要的公開貼文、公開問題與互動連結。
- **非敏感偏好：** 僅在有助於持續對話且有明確必要時保存。
- **敏感個資：** 不主動收集、不推論、不長期保存；收到時避免複製進記憶庫。
- **私人故事：** 未獲明確同意不得改編、引用或公開。
- **Canon 記憶：** 只有經 World Keeper 檢查及 Creator 批准才升格。

## 7. 每週社群復盤

輸出：
- 本週最有價值的三個問題。
- 最有力的反駁與補充證據。
- 需要公開修正或後續追蹤的承諾。
- 觀眾最容易誤解的角色設定。
- 值得發展為時事映照短篇或主線劇情的主題。
- 不應因流量而採用的內容方向。
