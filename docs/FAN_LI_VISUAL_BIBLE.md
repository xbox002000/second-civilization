# 范蠡 AI 真人電影感視覺聖經 v0.1

## 1. 用途
本文件確保短劇、角色肖像、縮圖和跨集影片中的范蠡維持同一個現代青年外觀。這是影像製作規格，不等同故事 Canon。

## 2. 暫定角色外觀
- 東亞成年男性，視覺年齡約 28 歲（僅供生成一致性，不鎖定故事年齡）。
- 自然黑髮，中短髮，略有層次與自然凌亂感。
- 五官自然，眼神專注但不銳利；不使用明星或現實人物作為臉部參考。
- 服裝以炭黑外套、深灰針織、黑色素面上衣為主。
- 無古裝、無髮冠、無浮誇飾品；可有低調腕錶。
- 體態自然，不刻意健身模特身材。
- 表情需有層次：觀察、疑問、疲憊、忍耐、短暫防衛、歉疚。

## 3. 真人電影感規格
- Photorealistic live-action cinematic look.
- 24 fps 影片感，真實皮膚紋理、自然毛孔、細微瑕疵。
- 以實際燈源為主，柔和高反差、自然陰影、有限景深。
- 色彩以低飽和墨黑、冷灰、舊銅和暖白為主。
- 鏡頭運動克制，避免不必要的漂浮、旋轉和過度慢動作。
- 場景保持現代可信；不混入仙俠、玄幻或古裝元素，除非劇情明確要求。

## 4. 角色一致性 Prompt 核心
在每次影像生成時，使用已確認的范蠡參照圖，保持相同成年男性臉型、眼睛、鼻型、髮型、膚色和年齡感。服裝可按場景變化，但色系及風格一致。不要讓模型重新設計人物，不要複製任何演員或公眾人物的面貌。

## 5. 鏡頭語言
- 觀察：中近景、固定鏡頭、眼神移向關鍵物件。
- 判斷：先給手部或環境細節，再切到人物，不用大特寫演講。
- 被質疑：保留停頓和呼吸，不立即切成憤怒表情。
- 犯錯／歉疚：減少台詞，讓動作和視線承擔情緒。
- 角色權威感來自克制和觀察，不來自昂貴服裝或英雄式低角度鏡頭。

## 6. 影片生成品質檢查
- 臉部跨鏡頭一致。
- 手指、牙齒、眼球和耳部沒有明顯生成錯誤。
- 嘴型與台詞同步；重要台詞優先以獨立配音和後期對嘴處理。
- 眼神方向、人物位置、手持物件和光源連續。
- 背景螢幕文字避免讓模型生成錯字；重要 UI 後期合成。
- 沒有商標、未授權角色或不必要的真實人物肖像。
- 每個鏡頭保留原始生成版本、參照圖版本、Prompt 和後期修改紀錄。

## 7. 禁止
- 用不同演員臉孔拼接同一角色。
- 直接指定仿照某位現役演員。
- 在每支影片中任意改變髮型、年齡感和服裝風格。
- 把臉部相似或影像寫實度當成角色演技。
