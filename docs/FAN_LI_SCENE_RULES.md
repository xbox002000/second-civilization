# 范蠡場景寫作規則 v0.1

## 一場戲中，如何讓觀眾感覺他高出一層

1. **別讓他先搶答案。** 先讓其他人展示自己如何理解問題。
2. **讓他找出問題的隱藏前提。** 他不只回答問題，而是指出大家共同忽略的前提。
3. **給他可追溯的依據。** 他看到的東西必須存在於合同、時間線、行為、數字、關係或先前伏筆裡。
4. **讓他擁有實際選項。** 他不是只能給建議的人；他可能掌握資金、資訊、渠道、時間或拒絕合作的能力。
5. **讓他提出交換，而非免費救援。** 他的合作必須有條件，也要對自己不利的部分負責。
6. **讓別人有能力反制。** 技術、法律、情感或資本領域都可能有比他更懂的人。
7. **讓他留下代價。** 高明的選擇不等於無痛的選擇。

## 角色對話比例
- 其他人物可以說得比他多。
- 范蠡的重要對白應短、具體，且改變下一步行動。
- 不必每場戲都有金句；有時他只問一個問題，然後讓別人去做。
- 他的沉默必須有觀察或選擇的作用，不可純粹裝神秘。

## 避免的低級表現
- 配角輪流稱讚他聰明。
- 對手只會咆哮或犯低級錯誤。
- 主角只靠旁白解釋，從不實際承擔決策。
- 一句話就讓所有人頓悟、臣服。
- 每集都安排一個「早在我計算之中」的反轉。
- 把對人的冷漠誤當成境界高。
- 將他所有策略都包裝成道德正確。

## 範例：同一個問題的低階與高階寫法

**低階：**
「你把交付承諾押在一個不能控制的開關上。」

**高階：**
阿呈：「現在要去哪裡找算力？」

范蠡沒有回答。他把桌上的合約翻到附件，指向一行被刪掉的備援條款。

范蠡：「先告訴我，這條是誰刪的？」

阿呈：「那時候為了降低成本。」

范蠡：「不是。你是為了讓簡報上的毛利更好看。」

他把合約推回去。

范蠡：「你今天缺的不是供應商。是你當初賣掉的選擇權。」

這段示範為本專案原創台詞；高位感來自事前留下的證據和對決策代價的追溯，而不是模仿既有作品。
