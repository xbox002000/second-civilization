## 永久發布閘門
- 公開發布、金融／政治／法律／醫療／公共安全／名譽與敏感內容均須人工審核。
- 不以演算法熱度取代證據品質。
- 不以觀眾互動自動修改 Canon 或 Persona Bible。

## 不先做
- 全自動公開發布
- 大型 Web 後台
- 新增昂貴模型或服務訂閱
- 未驗證即進行大量多平台轉製
- 為了流量把主角改成預言家、陰謀論者或成功學導師
