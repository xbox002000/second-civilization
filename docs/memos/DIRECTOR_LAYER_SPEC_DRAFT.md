# 導演層規格草案（Director's Layer）

> 起因：DEMO-01（2026-11-28）Creator 導演層回饋六點——主角傻愣無推進、三鏡光線跳變、鏡頭元素單調、奇幻事件無特效拍點、運鏡太穩缺慌亂感、古人現身鬧街路人無反應。診斷：現行規格只管「做對」（連戲／欄位／技術 QC），缺「拍得像回事」的一層。本草案將導演思維制度化為四件工件，插入 Gate A3（劇本鎖定）之後、分鏡包裝之前；粗剪後另設導演 QC 閘。
> 流程：本草案 → agy 工程討論 → Creator 拍板 → 併入分鏡規格（v2.1 增補）與 DESIGN。

## 一、導演闡述（Director's Statement，每集一份，分鏡開工前置）

每集在 script_pack 鎖定後、storyboard 包裝前，產出一份導演闡述，逐 segment 填寫：

| 段落欄位 | 內容 |
|---|---|
| 情緒曲線 | 本段觀眾情緒從何處到何處（如 驚→懼→強自鎮定） |
| 運鏡心理基調 | 本段鏡頭的心理狀態（失控／貼身／冷靜觀察／壓迫），與情緒曲線的對應 |
| 場景邏輯 | 事件為什麼發生在這個地點；地點的人口密度與主角異常度的匹配（異常度高→僻靜場景，或明寫人群反應） |
| 世界反應基調 | 環境與群演對異常事件的反應方式（側目／圍觀／拍攝／無人因由） |
| 特效拍點 | 本段奇幻／異常事件的視聽標記位置與手法（光變／glitch／聲場抽空／環境連動），無則明寫無 |
| 光線鎖定 | 本段時間帶與天氣（如 入夜藍調、濕地反光），全段鏡頭共用，變更須跨段交代 |

導演闡述由 Muse 主筆、Creator 拍板；未拍板的集數不得進入分鏡包裝。

## 二、分鏡新增欄位（併入 script_pack shots）

| 欄位 | 必填 | 說明 |
|---|---|---|
| `shot_intent` | ● | 這一鏡要讓觀眾感覺什麼（一句話，情緒詞＋對象，如「替他屏息：危險近了」） |
| `performance_beat` | ● | 鏡內狀態變化：起狀態→觸發→迄狀態（禁止只寫定格姿勢；靜止鏡須寫明「刻意靜止」的意圖） |
| `world_reaction` | ● | 群演／環境反應：none（須附理由，如僻靜場景）／glance／double_take／filming／flee／ambient（環境連動，如燈閃、犬吠） |
| `camera_psychology` | ● | 枚舉：`stable_control`／`handheld_anxiety`／`subjective_pov`／`predator_stalk`／`cold_observe`／`intimate_drift`；衍生時映射至運鏡附錄的 movement 與 named_shot（如 handheld_anxiety→handheld＋不規則微晃＋跟拍遲滯） |
| `vfx_beat` | ○ | 枚舉：`none`／`glitch_in`／`light_shift`／`sound_drop`／`env_reaction`／`composite_ui`；非 none 時必填 `vfx_note` 一句手法 |
| `light_lock_id` | ● | 指向導演闡述的光線鎖定條目；同 segment 內全鏡共用 |

## 三、驗證規則增補（V12 導演護欄）

- **V12a 光線硬閘**：同 segment 內 `light_lock_id` 不一致，或成片抽幀光線色溫與鎖定條目明顯不符 → 駁回。
- **V12b 表演拍完整性**：`performance_beat` 缺起迄狀態變化且未標刻意靜止 → 分鏡包裝不通過。
- **V12c 世界反應合理性**：公開場景＋主角異常度高（古裝／異象）＋`world_reaction=none` 且無理由 → 駁回（DEMO-01 第 6 點的制度化）。
- **V12d 鏡頭多元性（Advisory）**：同 segment 連續 3 鏡景別＋角度＋構圖重心全同 → 告警，導演闡述有明文理由者豁免。
- **V12e 運鏡心理一致性**：`camera_psychology` 與 movement 衍生結果衝突（如標 anxiety 卻衍生出穩定推軌）→ 告警。

## 四、導演 QC 閘（QC-D，粗剪後、技術 QC 之外獨立一關）

逐項以「過／不過＋一句證據」評，任一不過退回對應工位：

1. **合理性**：世界對異常的反應成立（路人、環境、物理）。
2. **情緒可讀**：抽掉對白，情緒曲線還讀得出來。
3. **鏡頭多元**：整集景別／角度／運動型態有變化，節奏有呼吸。
4. **光線連續**：同段不跳天氣、不跳色溫。
5. **運鏡心理**：鏡頭狀態與角色心理同步（慌則晃、定則穩）。
6. **特效拍點**：奇幻事件有被「拍成事件」，不是只是出現在畫面裡。

QC-D 由 Muse 初評、Creator 終判；不過的項目連同證據回寫導演手記。

## 五、導演手記（Director's Playbook，累積制）

- 檔案：`bible/director/playbook.md`（repo 內），一條裁示一條目：日期／出處（哪支片哪次回饋）／規則／適用範圍。
- 種子條目（2026-11-28，DEMO-01 回饋）：
  1. 主角每鏡必須有狀態變化，禁止傻愣定格（靜止須是刻意選擇）。
  2. 同段光線與天氣鎖死，跳變必須是劇情事件並有交代。
  3. 連續鏡頭要變換景別／角度／構圖，單調即失敗。
  4. 奇幻事件（穿越、系統、異象）必須有特效拍點標記其「事件性」。
  5. 運鏡跟著角色心理走：慌亂要晃、要遲滯；鎮定才許穩。
  6. 異常者現身公共場合，世界必須有反應；不要反應，就把場景搬到僻靜處（巷弄）。
- 每集導演闡述開筆前先讀手記；QC-D 檢查表與手記同步增修。

## 六、與既有規格的關係

- 分鏡規格 v2：新增第二節五欄位＋一欄 light_lock_id、V12 規則、QC-D 掛在既有 QC-2 之後（QC-D 不過，技術 QC 不啟動，省工）。
- 運鏡附錄 A：`camera_psychology` 為 movement 衍生的上游輸入；named_shots 庫增補心理標籤。
- DESIGN：Stage 2（編劇）與 Stage 3（分鏡）之間插入「導演闡述」半階段（Stage 2.5），Gate A3 後、資產與分鏡開工前；工時估列入討論。
