# SYS-01 顯現方式 — Creator 導演定調（2026-11-28 21:18，判讀 SM-8 後）

用戶原話要點：「系統豆包出現的效果看起來還是很詭異，沒有那種忽然彈現在主角面前的那種感覺。如果不好表達也可以用分鏡來切。因為現在看起來系統豆包是浮在空中，這樣有點太過於仰視了，應該平視一些比較好。她可以是半透明狀的出現在主角面前。」

## 定調（取代 AMD-05 v3 尺度規則草案與 SM-8 首幀構圖）
1. **平視**：SYS-01 顯現採平視構圖，尺度 0.90–1.00×（與主角同高），站位在他**面前**、與他同一地平面（下身可粒子消散，但消散點落在地面附近，不是懸空漂浮）。仰視英雄尺度（1.25–1.45×）退場，不再作預設，含 2022 初現。
2. **彈現靠剪輯，不靠鏡內凝聚**：顯現語法以分鏡硬切為主——前一鏡給光 cue（他臉側冷青光閃＋環境聲抽空 sound_drop＋他視線轉向），硬切入下一鏡時她**已經在場**（半透明、平視、站位已定）。鏡內光凝成形降為偶爾點綴，不作主要表達。
3. **半透明**：維持 v3 投影質感（自然膚色、冷青輪廓光、粒子消散、無文字面板）——SM-8 已驗證此載體與質感（6/6 PASS、12 點）；本次否決的是**構圖與尺度**，不是技術路線。
