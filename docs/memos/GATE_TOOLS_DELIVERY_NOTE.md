## 3. Spec Notes & Minor Deviations

1. **QC-2 Six Key Names**: Standardized strictly on the brief and memo §二 AMD-03 schema names (`age_id`, `scar_side`, `costume_4pt`, `light_lock`, `expression_lip`, `pose_spatial`) rather than the prose table headers (`age_read`, `costume_details`) in memo §5.2.
2. **QC-2 Column Alignment Across Shot Types (§4.3 B + §5.1)**: Because §5.1 samples 3, 4, or 5 frames depending on shot type, `qc2_diff_sheet.jpg` dynamically allocates `max_samples` columns (5 columns for DEMO-02 because `S4` is a 5-frame dialogue shot) with unused slots marked `— N/A —`, keeping every shot row aligned while preserving native 720×1280 cell width and full §5.1 coverage.
3. **Peak Intra-Shot Light Excursion Flag**: Added `PEAK_LIGHT_SPIKE` (max `|L*(f_i) - L*(f_0)| > 12`) in addition to `f_0 -> f_end` drift so transient mid-clip flares like DEMO-02 `S1` (`dL* = +14.6` at 50% while returning near baseline at 100%) are automatically caught and flagged.
4. **Zero-Dependency Face Crop**: `diff_sheet_gen.py` uses a pure-numpy smoothness-weighted YCbCr skin detector (rejecting cyan holograms and textured alley walls) and also accepts optional normalized `face_box` / `clip_face_box` overrides in `shot_list.json` for extreme wide/tiny-face shots (`S2`, `S2R`, `S3b`, `S4`).
5. **SYS-01 Popup Zero-Text Mode**: Per brief Deliverable 3 (and because `Noto Sans TC` is not yet installed on this VM), `sys01_composite.py` renders pure geometric header accents and **zero text** in the popup panel layer.
6. **Layer 1 Dynamic Mask Speed Optimization**: The smooth feathered Gaussian mask for `maskedmerge` is generated at 1/4 resolution, time-modulated via `geq` with the exact §7.2 `alpha(t)` pulse/breath curve, and bilinear-upscaled to native frame resolution so 3s CPU rendering stays fast (~12s total including `showwaves` and H.264 encode).
