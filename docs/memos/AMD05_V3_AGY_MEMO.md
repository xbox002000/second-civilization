### 1.2 H3 Ref2VA 雙人槽位數學與 VRAM 硬邊界（誠實推演）

> **範疇聲明（H3 規格對賬補註）**：下方「4 槽上限」係針對我方 **Colab L4 24GB 跑 `ref_image_size="max"` 的本地硬體包絡**（H3 模型與官方 API 原生支援最多 9 張參考圖）。就「范蠡＋全息 `SYS-01`」而言，即使切換 A100 或官方 9 槽 API，第 3 點之「實心棚拍女像卡 vs 半透明全息」材質互斥與 Flow 體積光優勢依然成立；但若未來集數出現「**兩名實心真人對白同框**（如范蠡＋勾踐／文種）」，4 槽限制僅屬 L4 硬體邊界而非 H3 模型限制，切 A100／API 即可解鎖 6–9 槽。

為什麼 **(c-雙人) 無法在 Colab L4 上同時扛住「范蠡＋`SYS-01`＋全息質感」**？四筆實測硬帳一次講清：
1. **VRAM 餘裕見底**：SM-7A 與 `DEMO02_v2` 實測顯示，Colab L4 24GB 跑 4 槽 `ref_image_size="max"` 已吃掉 **`20.18–20.75 GiB` / `22.03 GiB`**（餘裕僅 `1.28–1.85 GiB`）。范蠡 4 槽（`<Pic 1>` 首幀＋`cu`/`45`/`45R`）若再硬加 1–2 張 `SYS-01` 參考圖至 5–6 槽，L4 極高機率直接 OOM（`preflight_gate.py` L1166 本就對 `>4` 圖發 `WARN`）；若降為 `ref_image_size="match"`，Clay Test 已證實會削弱古裝交領與臉部銳度。
2. **硬擠進 4 槽會破壞兩邊防線**：若砍掉范蠡的 `45` 與 `45R` 騰出 1 槽給 `SYS-01`（`<Pic 1>` 雙人首幀＋`<Pic 2>` 范蠡＋`<Pic 3..4>` `SYS-01`），范蠡就失去 SM-7A 驗證過的 3 視角防錯邊疤與 `右衽` 多數決保護；反之只給 `SYS-01` 1 槽，她的臉在動態下容易被 H3 當成次要背景人物糊掉。
3. **「實心棚拍卡 vs 半透明全息」材質互斥**：SM-7A Forensic Discovery #1 已證明 `<Pic 1>` 與 `<Pic 2..4>` 存在強烈注意力競爭。餵入棚拍實心女像給 H3 Ref2VA，模型會把「實心皮膚與黑羊毛布料」權重拉高，導致她越播越像站著的實心真人，或把全息掃描線外溢到范蠡身上。
4. **反過來，若「單鏡只拍 `SYS-01` 一人」則完全解套**：3–4 槽全給她（`<Pic 1>` QC-1 核准全息首幀＋`<Pic 2>` 單視角正面臉＋`<Pic 3>` 目標表情單格），總槽數 `≤ 4`、L4 `0 OOM`、無雙人身分串染，還能跑原生中文 `<d>` 口型。

### 1.3 關於 Carrier (a) 的唯一已知短板與對策：「從空氣中憑空凝聚」
- **短板**：`i2v_first` 必須在 Frame 0 就畫出 `SYS-01` 才能鎖住她的臉；若 Frame 0 是空巷、要求她於 `t=1.0s` 憑空長出來，影片模型沒有她的參考圖，臉必然隨機換人。
- **三種零浪費解法（依優先序）**：
  1. **剪輯節奏解（首選，0 額外花費）**：前鏡（如 `S02` 尾或 `S3a`）范蠡見冷青微光亮起／轉頭 → `sound_drop`（`0.35s`）＋冷光閃脈剪輯接點 → 硬切進入本鏡 Frame 0 **她已剛凝聚成形於眼前**（首 `0.25s` 可於後製對全息區疊極輕亮度浮入＋色散收斂），觀眾體感即「她突然出現在他面前」。
  2. **`i2v_first_last` 兩端鎖（待 SM-5 驗證後啟用）**：Frame 0 = 乾淨空景＋冷青光團，End Frame = QC-1 核准之 `SYS-01` 雙人全息圖（兩張皆 `nano2` 0 點產出），由 `omni-1.2-flash`（原生支援 `--end-frame` 達 10s）自動完成粒子聚合過渡。
  3. **Carrier (b) `r2v` 備援**：僅當劇本絕對禁止切鏡且 `i2v_first_last` 失效時啟用。

### 尺度一致性與跨鏡過渡硬規則
1. **同場同拍鎖尺度（零無故縮放跳剪）**：同一場段（`segment_id`）內，連續相鄰鏡透過 **AMD-04 Path A（`derived_shot`）** 繼承前鏡空間尺度，QC-1 檢核 `SYS-01` 頭高與位置漂移 **`≤ ±10%`**。
