# 《第二次文明》開局弧線 001｜前三章設計

> 版本：v0.1  
> 狀態：劇情提案／非 Canon。  
> 用途：把「范蠡轉世、記憶甦醒、AI 系統登場、第一場現代實戰」做成連續三章，而不是把設定一次講完。  
> 暫定姓名「林既明」、小型 AI 工作流團隊、電商客戶與交付事故，全部只是戲劇測試材料；Creator 尚未核准。

## 一、開局要交付給讀者的承諾

這不是一個古人得到神秘外掛後輕易碾壓現代人的故事。

這是一個曾經理解人性、時機、資源與權力的人，轉生到人人都能使用 AI 的年代。他擁有前世累積的判斷習慣，卻沒有現代技術、法律、平台和制度的完整知識。他必須重新學習這個世界。

故事的核心爽點是：

1. **記憶爽點：** 他不是在讀范蠡的故事，而是以第一人稱想起某些只有身處其中才會記得的細節；但記憶仍須與史料和其他解釋交叉檢驗。
2. **系統爽點：** AI 不只是回答問題，而是被他組織成一套長期運作的認知系統：記錄、查證、拆局、反駁、推演和受控執行。
3. **認知爽點：** 別人問「AI 怎麼修好」，他先問「誰授權它承諾、它依據什麼資料、誰會承擔結果」。
4. **反轉爽點：** 他不靠神奇知識一次解決全部問題，而是抓住真正的控制點，將一場看似只能全盤背鍋的事故，拆成可處理的責任與行動。
5. **成長爽點：** AI 與現代專業人士可以指出他錯在哪裡；他願意修正，下一次才會更強。

## 二、試寫所用的現代危機

一支四人左右的小型 AI 工作流團隊，替一家網路商店部署訂單助理。某晚，庫存同步延遲，Agent 仍根據舊資料自動向顧客確認了 47 筆訂單，其中部分商品實際上已經缺貨。

天亮前，店主要求團隊交代責任，並暗示將要求全額賠償。團隊內部開始互相指責：有人認為是模型幻覺，有人認為客戶資料錯誤，有人想直接關閉整套服務，也有人想先寫一份道歉聲明把責任全部攬下來。

這個事件適合開局，因為它同時包含：
- 技術問題：舊庫存資料、同步延遲、Agent 權限設計。
- 商業問題：合約範圍、客戶承諾、賠償責任與續約風險。
- 人性問題：每個人都想先降低自己的損失。
- 范蠡的切入點：真正失控的不只是模型輸出，而是「誰能代表團隊向外作出承諾，以及承諾依據什麼」。

**重要限制：** 范蠡不能憑空知道日誌內容、程式原因或法律責任。他必須讓技術人員查系統，讓 AI 整理資料，並把尚未證實的判斷明確標示為假設。

## 三、第一章｜醒來的人

**章節任務：** 讓讀者感受到轉生記憶正在甦醒，讓 AI 系統正式登場，最後把主角推進一場無法旁觀的現代危機。

### 節拍
1. 以古代場景的第一人稱感官片段開場：潮濕的木案、越國朝堂、勾踐的等待、文種的眼神，以及自己說出「還不到時候」的瞬間。
2. 猛然醒在現代青年身體裡。現代生活的記憶完整存在，古代記憶卻像另一段真實人生；不是肉身穿越，而是兩段人生在同一個意識中重疊。
3. 主角打開平常使用的 AI。AI 不宣稱他是范蠡，先列出記憶重組、既有知識、睡眠壓力等替代解釋，並要求記錄可驗證細節。
4. 主角提出系統需求：長期記錄、區分史實與主觀記憶、保留來源、反駁他的推論；任何對外行動都要先取得授權。
5. 他把這份長期研究檔案命名為「范蠡」。這是他的假設與自我辨認，不是 AI 對轉世的認證。
6. 團隊群組突然跳出事故：Agent 對外確認了 47 筆訂單，部分缺貨。店主要求天亮前給出責任說明。

### 章末鉤子
群組裡所有人都在問：「到底是哪個模型出錯？」

主角看著那 47 筆訂單，回了一句：

**「先別問它為什麼說了。先查清楚，誰給了它替我們答應別人的權力。」**

## 四、第二章｜誰替你答應

**章節任務：** 展示主角如何使用 AI 系統，並讓 AI 第一次真正反駁他。

### 節拍
1. 團隊成員各自使用 AI：有人請它寫道歉聲明，有人請它找模型 Bug，有人請它估算賠償金額。所有人都在得到答案，卻沒有先確定問題。
2. 主角建立案件檔案，要求 AI 把資訊分成四類：已確認事實、未確認推論、缺失證據、可能的利益衝突。
3. 他不先問「誰有錯」，而要求畫出資料來源、授權流程、對外承諾與責任鏈：庫存由誰更新？Agent 讀取哪個版本？誰設定自動確認？誰批准這項權限？
4. 技術合夥人指出：問題可能是庫存同步與訂單鎖定機制，而非模型本身。主角必須承認自己對現代系統架構並不熟悉。
5. AI 的反方報告指出主角的第一個直覺也有漏洞：客戶提供舊庫存資料，不代表團隊就能免除責任；團隊既然讓 Agent 自動對外承諾，就應該設置防錯與升級機制。
6. 主角接受這項反駁，將目標從「證明責任不在我方」改成「先停止新增損害，再用證據切分責任」。

### 章末鉤子
日誌終於調出來：47 筆訂單不是全部都錯。真正缺貨的只有 12 筆；另外 35 筆仍可正常履約。

但系統權限紀錄顯示，Agent 曾被允許直接發出最終確認訊息。

**他們面對的不是一個會說錯話的模型，而是一個被授權替人作出承諾、卻沒有承擔承諾後果的系統。**

## 五、第三章｜先止血，再算帳

**章節任務：** 交付第一個看得見的戰術勝利，建立范蠡的高位感，但不讓他成為全知的神。

### 節拍
1. 團隊內部出現三種方案：關閉所有服務、先道歉並接受全額賠償、或把責任推給客戶資料。每種方案都只保護了部分人的利益。
2. 主角提出分層處理：立即關閉 Agent 的「最終確認／對外承諾」權限，但保留查詢、分類與草擬能力；47 筆訂單逐筆由人員複核。
3. 技術合夥人負責修正權限和同步流程；AI 負責整理日誌、比對訂單、產生顧客通知草稿；主角負責排序、責任協商和對外溝通。三者不可互相取代。
4. 對客戶不先爭辯責任，而是提交一份能驗收的處理表：35 筆照常履約、12 筆逐一聯絡並提供取消或替代方案；同時承認團隊在自動確認權限設計上的疏失。
5. 客戶原本要求全額賠償並立即終止合作。看見逐筆清單、可追溯日誌和具體補救時程後，同意先給團隊六小時完成處理與複核，再依實際損失談責任。
6. 這不是范蠡單方面勝利：團隊必須承擔部分補救成本，技術合夥人要求暫停所有未經驗收的自動承諾功能；客戶也保留終止合約的權利。
7. 事後 AI 產生反方復盤：主角成功改變了談判框架，但仍未完全確認客戶為何堅持全額求償，也未證明所有 12 筆缺貨都由同一原因造成。

### 第一個爽點
所有人爭著找一個人或一個模型來背鍋時，范蠡先切斷「未經核實的承諾」，再把混成一團的 47 筆訂單拆成可處理的 35 與 12。

他沒有靠嘴贏，而是讓局面從「立刻全盤賠償」變成「有證據、有順序、有期限的處理方案」。

### 章末鉤子
事故暫時止血。AI 卻在復盤最後標出一項：

**「你的策略有效，但你對客戶動機的判斷，仍然缺乏證據。」**

他看著那行字，第一次確認：這套系統不會替他證明自己。

它會逼他證明自己。

## 六、故事中的 AI「系統」如何呈現

系統必須讓讀者看得見、記得住，但它仍是普及 AI 工具經過主角個人化組織後形成的工作介面，不是只有主角才能使用的超自然外掛。

### 案件面板示意

```text
┌─ 范蠡｜局勢檔案 ─────────────────┐
│ 案件：訂單助理交付事故                 │
│                                      │
│ 已確認：47 筆自動確認訊息              │
│ 已確認：12 筆商品缺貨                  │
│ 待查證：庫存同步延遲的根本原因          │
│ 待查證：客戶是否曾修改庫存資料          │
│                                      │
│ 關鍵控制點：Agent 對外承諾權限          │
│ 主要風險：新增錯誤承諾／延誤履約         │
│                                      │
│ 反方提醒：資料錯誤不等於責任免除         │
│ 建議下一步：凍結承諾權限、逐筆複核       │
│                                      │
│ Agent 執行：未授權                     │
└──────────────────────────────────────┘
```

### 五個核心功能
| 功能 | 故事用途 | 邊界 |
|---|---|---|
| 記憶與知識檔案 | 累積前世片段、史料、現代事件和決策紀錄 | 不把主觀記憶自動升格為史實 |
| 研究與查證 | 搜尋來源、整理日誌、比對證據 | 受資料品質、工具與模型能力限制 |
| 局勢分析 | 拆解利益、依賴、權限、承諾和風險 | 分析結果是模型，不是事實本身 |
| 反方辯論 | 主動尋找反例、替代解釋與盲點 | 可能錯誤，也要接受主角檢驗 |
| Agent 執行 | 在明確授權下操作工具或流程 | 高風險行動需人工核准、日誌與可撤回機制 |

**不要引入** 經驗值、等級、技能點、神秘任務獎勵或只有主角看得到的世界數值。系統成長來自資料、流程、工具、可靠度與主角的使用能力提升。

## 七、前三章之後的推進

- EP01 後段：主角開始把 AI 當成認知系統，逐步摸索現代世界的規則；前世記憶仍分批浮現。
- EP02《入場條款》：當他已有一次實際交付經驗，才進入平台、資本、客戶關係與服務路由的談判。
- 中段：Agent 服務網絡成為他的長期實驗，但每次擴張都要面對品質、責任、資料權限和客戶入口的現實阻力。
- 公眾人格線：范蠡開始公開記錄觀察與推論，讓外界可以反駁和檢驗；公開內容不自動改寫主線 Canon。
