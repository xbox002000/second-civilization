# 《第二次文明》媒體工作流 v0.2

## A. 端到端總流程

```text
主流事件／觀眾提問／長期議題
          ↓
趨勢收件與選題
          ↓
研究 → 事實查核 → 系統分析
          ↓
范蠡獨立初判 → AI Red Team／專家挑戰
          ↓
        編輯分流
        ↙       ↘
 公眾思想線       故事宇宙線
 觀局／推演       時事映照／主線提案
 答眾／長文       短篇／連載
        ↘       ↙
         短劇／影音製作
                ↓
         獨立審稿與人工核准
                ↓
          發布與社群互動
                ↓
      公開發言／預測／留言記憶
                ↓
        更正、稽核、每週復盤
                ↓
       經批准後更新人格與 Canon
```

## B. 階段與退出條件

| 階段 | 負責角色 | 工作 | 退出條件 |
|---|---|---|---|
| S0 趨勢收件 | Producer | 建立 Event ID、收件時間與候選內容 | 有事件線索、受眾問題與初步相關性 |
| S1 研究 | Researcher | 原始來源、時間線、各方說法 | 重要主張有來源；未知數已列 |
| S2 查核 | Fact Checker | 逐項驗證來源、數字、引用和時間 | 主張有狀態；未證實處揭露 |
| S3 系統分析 | Systems Analyst | 利益、資源、權力、依賴與情境 | 有替代解釋、反證條件與受影響者 |
| S4 范蠡初判 | Persona / Writer | 獨立形成觀點與盲點 | 有核心觀察、暫時判斷、未知數與修正條件 |
| S5 反方挑戰 | Red Team / Expert | 找最強反駁與專業盲點 | 反駁有依據，不是形式唱反調 |
| S6 編輯分流 | Producer | 選擇公眾內容、短篇、主線或短劇 | 每種格式有受眾價值和邊界 |
| S7 格式製作 | Writer / Format Producer / Director | 觀局、推演、答眾、短篇、主線、短劇 | 符合格式模板、來源與角色連續性 |
| S8 獨立審稿 | Reviewer | 事實、推理、人格、Canon、授權與風險 | PASS 或列出具體返工項目 |
| S9 人工核准 | Creator | 決定是否公開、製作與發布 | 核准者、版本、時間和範圍已記錄 |
| S10 發布 | Format Producer | 平台版本、素材、字幕、封面與發布 | URL、時間、素材版本入庫 |
| S11 社群互動 | Community Editor | 分類留言、回覆、追蹤新證據 | 回覆草稿、升級任務與記憶候選完成 |
| S12 復盤 | Performance Analyst / Producer | 指標、預測稽核、觀眾問題與角色成長 | 形成下一輪假設與待辦 |

## C. 內容分流
- 現世觀局：事實充分且具有公共價值的時事分析。
- 事勢推演：有明確期限、觀測指標與反證條件的判斷。
- 時事映照：以現實命題創作的非 Canon 短篇。
- 主線連載：需 World Keeper 檢查及 Creator 批准才進入 Canon。
- 短劇：標明來自主線、時事映照或角色微劇場。
- 范蠡答眾：回答問題、反駁與補充證據。

不是每一則事件都要做成所有格式。Producer 依時效、證據、敘事強度、製作成本與角色價值分流。

## D. 狀態機
`INBOX → RESEARCHING → FACT_CHECK → ANALYZING → FAN_LI_FIRST_VIEW → RED_TEAM → EDITORIAL_SPLIT → DRAFTING → REVIEW → HUMAN_APPROVAL → PRODUCTION → PUBLISHED → COMMUNITY → RETROSPECTIVE`

退回狀態：`NEEDS_SOURCES`、`NEEDS_FACT_CHECK`、`NEEDS_ANALYSIS`、`NEEDS_REVISION`、`NEEDS_CONTINUITY_FIX`、`BLOCKED`、`REJECTED`。

## E. 公開承諾與預測
任何可驗證的公開推論都要保存建立時間、資料截止時間、期限、成功條件、反證條件和結果。不可刪除失敗紀錄；重要更正需連回原始貼文。公開承諾必須建立追蹤任務後才能對觀眾承諾。

## F. 人工核准
任何對外發布都要人工核准。金融、政治、法律、醫療、公共安全、名譽指控、未成年人、真實受害者與高風險議題提高審核標準；必要時不發布或不做虛構改編。

## G. MVP 驗收
用一個真實事件完成：
- 研究卡、查核報告、系統分析、范蠡初判和 Red Team。
- 一篇現世觀局貼文。
- 一則公開推論紀錄（若不適合預測，需說明）。
- 一篇非 Canon 時事映照短篇。
- 一支 45–90 秒短劇腳本與分鏡。
- 一組社群回覆草稿。
- Reviewer 報告與人工核准紀錄。
- 發布後的留言分類與復盤模板。
