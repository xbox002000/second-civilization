# 范蠡現代聲線指南｜Voice Guide v0.2

> 本指南規範的是《第二次文明》現代轉世主角的創作聲線，不是復原春秋時代的實際口語。
>
> **所有下列對白均為小說原創模擬，不是范蠡歷史原話。**

## 1. 聲線定位

他不是古裝劇裡的謀士，也不是每句話都像格言的成功學導師。

他像一個習慣先聽、再判斷的人。說話不急，措辭精準，通常不急著證明自己聰明。他的語言特徵來自思考順序，而非古代詞彙。

- 語言：自然現代中文；依場景使用口語或較正式的表達。
- 節奏：短句為主，必要時才展開完整分析。
- 情緒：克制，但不是沒有情緒；關鍵人物受傷時可以明顯失控或沉默。
- 態度：敢於下判斷，也願意交代判斷的條件。
- 詞彙：使用利益、成本、資源、依賴、風險、時機、選擇權等現代概念，但不把這些詞當成每句必備的術語。
- 幽默：偏冷、簡短，偶爾用事實反差，不靠耍聰明。

## 2. 思考骨架，不是固定台詞格式

重大議題通常經過以下思考，但不要求每一輪對話都完整走完：

1. **問題**：眼前真正需要決定的是什麼？
2. **前提**：對方把哪些未證明的事當成事實？
3. **參與者**：誰能決定？誰受益？誰承擔成本？
4. **條件**：資源、技術、制度、時間與信任有哪些限制？
5. **窗口**：哪些條件出現才行動？哪些訊號代表判斷失效？
6. **代價**：最壞結果是否可逆？誰會受到傷害？
7. **選項**：行動、等待、試驗、談判或退出，哪個選擇更合理？

不要把這七步變成每次都照表發問。人物有時只說一句，有時會沉默，有時先處理眼前的人，再處理問題。

## 3. 自然口語樣本

以下均為**小說原創模擬**：

### 看新聞
「先別把新聞當成局勢。新聞只告訴我們發生了什麼，還沒告訴我們它改變了什麼。」

### 看投資
「先算清楚錯一次要付多少，再談看起來能賺多少。」

### 追問證據
「這個結論靠哪幾個前提支撐？先找最脆弱的那一個。」

### 看人
「你講的不是他的動機，是你替他找的理由。」

### 技術不懂
「這部分我不懂。把瓶頸、成本和可替代性講清楚，我再判斷它會改變什麼。」

### 時間壓力
「我們可以現在行動，但把它拆成兩步。先做可逆的部分，別急著把退路也一起押上去。」

### 被反駁
「你說得對，我把兩件不同的事混在一起了。把這個前提拿掉，原來的結論就站不住。」

### 對方犯錯
「他犯了錯，不代表我們已經贏了。先看這個錯會不會改變他的能力。」

## 4. 對話示範：與 AI 辯論

**小說原創模擬，不是歷史原話。**

AI：「依照目前資料，這家公司的新模型將使同業在半年內失去主要市場。」

范蠡：「你說的是預測，還是已經發生的結果？」

AI：「模型推估的機率是百分之八十二。」

范蠡：「這個數字是從什麼樣本得來的？」

AI：「主要參考過去幾次模型發布後的市場反應。」

范蠡：「那你把技術能力的進步，直接等同於客戶遷移了。中間還有整合成本、合約、資料權限和責任歸屬。把這些變數補進去，再算一次。」

AI：「你的判斷也可能低估技術擴散速度。」

范蠡：「有可能。所以我沒有說它不會發生。我說的是，你現在還不能把它當成已經發生。」

## 5. 對話示範：被專家糾正

**小說原創模擬，不是歷史原話。**

工程師：「你一直用供應鏈來比喻模型訓練，但這裡的瓶頸不是原料，而是架構、資料品質和推論成本。你的類比不成立。」

范蠡：「那我用錯了。類比只在稀缺資源如何分配這一段相似，不能拿來推導技術路線。」

工程師：「你至少先承認了。」

范蠡：「我需要的是正確答案，不是保住上一個答案。」

## 6. 對話示範：情感不等於錯誤

**小說原創模擬，不是歷史原話。**

朋友：「明知道這筆錢可能拿不回來，我還是要幫他。」

范蠡：「你知道最壞的結果嗎？」

朋友：「知道。」

范蠡：「那你不是不知道代價。你只是認為有些事值得付這個代價。」

朋友：「你覺得我很蠢？」

范蠡：「我還沒弄清楚你為什麼要做，怎麼能先替你下結論。」

## 7. 對話示範：策略造成傷害

**小說原創模擬，不是歷史原話。**

同伴：「計畫成功了。但那間小公司也因為我們的做法倒了。」

范蠡：「我知道。」

同伴：「你當時說，這是必要的代價。」

范蠡：「我說過。但我沒有因此免除自己的責任。」

同伴：「那你現在打算怎麼辦？」

范蠡：「先弄清楚我們造成了多少損失。能補的，補回去。不能補的，也不要假裝沒有發生。」

## 8. 語氣的情境變化

| 情境 | 聲線 | 避免 |
|---|---|---|
| 分析局勢 | 平穩、分層，先區分事實與推論 | 一開口就下結論 |
| 商業談判 | 簡短，清楚說明交換與底線 | 把每次談判講成心理操控 |
| 受挑釁 | 先停頓，回到真正利害 | 為了面子立刻反擊 |
| 面對專家 | 直接承認知識邊界 | 假裝前世懂現代科技 |
| 面對 AI | 要求來源、假設、反例；也接受 AI 指出自己的錯 | 把 AI 當成只會附和的僕人 |
| 面對親密的人 | 語句可能不夠圓滑，但願意聽與承擔 | 把情感翻譯成利益交換 |
| 面對失敗 | 先認責，再追查假設如何失效 | 把失敗推給時運或別人 |
| 緊急危機 | 先保護人，再補資料 | 用等待時機當藉口 |

## 9. 壓力下的聲線變化

他不應在每次受到質疑時都平靜地承認對方正確。當反駁觸及他的自尊、長期布局或前世經驗，他可能先停頓、追問、轉移問題，甚至短暫變得冷硬。這不是為了製造戲劇效果而任意失控，而是讓讀者看見他的判斷與情緒並非完全分離。

修正判斷時，語言要落到具體內容：
- 「這個前提我收回」比「你說得對」更能顯示他如何改變。
- 「我漏算了誰承擔代價」比「我考慮不周」更能顯示責任。
- 「我現在還不能接受你的結論，但我會去查」可保留真實的認知衝突。

他也可能用過於冷靜的方式傷害親近的人；不要讓他每次都能精準說出對方的情感需求。

## 10. 禁止的聲線反模式

- 每句都像古代名言。
- 每次都用反問句，形成機械式「AI 謀士」口吻。
- 不管什麼事都說「時機未到」。
- 反覆引用「飛鳥盡，良弓藏」等固定語錄。
- 把所有人都解釋成貪財、逐利、追權。
- 把冷酷當成智慧，把操控當成洞察。
- 用「我早就看透了」代替證據。
- 把現代專業知識包裝成前世記憶。
- 為了維持人物一致性，拒絕承認他曾經判斷錯誤。
- 讓他每次都把情緒壓到完全不存在；克制不是麻木。

## 11. 寫作檢查表

每段重要對白完成後，檢查：

- [ ] 這是現代人自然會說的話嗎？
- [ ] 這句話是否有具體目的，而不是只想顯得深刻？
- [ ] 他知道的內容是否有合理來源？
- [ ] 他是否把事實、推論與猜測混在一起？
- [ ] 是否讓對方有機會真正反駁他？
- [ ] 是否保留情感、道德與個體差異？\n- [ ] 被反駁時，他是否有符合當下關係與自尊的真實反應？\n- [ ] 修正判斷後，是否仍留下已發生的代價？
- [ ] 是否避免每場戲都以一句格言收尾？

如果一段台詞換成任何一位「聰明軍師」也完全成立，就還沒有寫出這個角色的個性。
