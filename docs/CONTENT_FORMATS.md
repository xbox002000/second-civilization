# 公眾內容格式與故事分類 v0.1

## 1. 核心原則

同一個事件資料包可以支援多種內容，但每種內容必須有自己的目的、事實邊界、受眾期待和驗收標準。不要把一則新聞同時塞進一篇評論、一篇虛構故事和一支短劇，卻不說明哪些是事實、哪些是創作。

## 2. 六種格式

### A. 現世觀局（Reality Brief）
**目的：** 讓群眾看到范蠡如何理解當下事件。
- 開頭：指出大家正在討論的現象或常見解讀。
- 核心：提出被忽略的條件、利害關係或因果問題。
- 支撐：引用可查核事實，標明時間點。
- 結尾：留下判斷、未知數或值得追問的問題。
- 禁止：沒有證據的內幕、把推測說成已發生事實。

### B. 事勢推演（Scenario / Forecast）
**目的：** 公開一個可以在未來被檢驗的判斷。
每一則至少記錄：
- 建立時間、資料截止時間、預測期限。
- 可觀測結果與成功條件。
- 主要假設與信心水準；資料不足時可以拒絕量化機率。
- 可能使推論失效的反證指標。
- 到期結果與事後解釋。
不要寫「一定會」「必然崩盤」等無條件預言。

### C. 時事映照短篇（Event Fiction）
**目的：** 快速把現實事件背後的人性、制度或選擇衝突變成可讀故事。
- 預設為非 Canon 的獨立故事。
- 以抽象命題、虛構角色或複合人物重構，不直接影射特定真人作為犯罪者。
- 可以保留事件的結構性啟發，但不保留未證實指控。
- 明確標示「受某類現象啟發的虛構作品」，必要時加註靈感事件與真實事件的差異。
- 篇幅和節奏服務於故事，而不是把時事分析換成幾個角色名字。

### D. 第二次文明主線（Main Canon）
**目的：** 推進范蠡轉世後的長期人生、人物關係與文明命題。
- 只有經 World Keeper 檢查及 Creator 批准，才能進入 Canon。
- 角色成長、重大關係、世界觀規則、主線事件要維持長期一致。
- 不必每集都追逐當週新聞；主線有自己的節奏和因果。
- 真實事件可以提供題材，但不得把未經查證的現實人物動機搬進主線。

### E. 短劇／微電影（Screen Story）
**目的：** 以視聽動作表現衝突，不是替文章配圖。
腳本至少包括：第一秒的視覺／情境鉤子、角色目標、阻力、選擇、代價或反轉、結尾懸念／問題、場景與素材需求。
短劇需標註來源故事：Main Canon 或 Event Fiction。不得混淆。

### F. 范蠡答眾（Public Dialogue）
**目的：** 讓帳號和群眾形成持續關係。
- 回答真問題、補充證據、澄清誤讀、承認不知道。
- 對有力反駁要回應內容，不要以名言或人格權威壓過對方。
- 適合延伸成後續觀局帖的問題，回收到選題池。
- 涉及私人資訊、敏感問題、金融／法律／醫療等高風險領域時，不讓角色以權威身份替觀眾作個人決策。

## 3. 同一題材的多格式拆分示例

假設主流新聞談某大型科技公司推出成本大幅下降的新模型：
1. 現世觀局：成本下降改變了誰的議價權？哪些成本沒有下降？
2. 事勢推演：未來 90 天，哪些客戶流程可能開始遷移？用何種指標驗證？
3. 時事映照短篇：一座城市的水價突然下降，掌握水源、管線和土地的人開始重新談判。
4. 主線故事：只有當此事件確實推動主角人生和主線衝突，且經批准才採用。
5. 短劇：以水城故事呈現資源價格改變後，商人、工匠和居民的不同選擇。
6. 范蠡答眾：回覆「既然模型免費，為什麼企業還不全部換掉？」並把問題收回觀局帖。

以上是格式示例，不是對任何特定公司的事實主張。

## 4. 一個事件的分流判斷

- **證據強、時效高、公共影響大：** 優先做現世觀局。
- **有可追蹤結果與期限：** 可做事勢推演。
- **人性衝突明確、可以抽象化：** 可做時事映照短篇。
- **能改變主角命運或長期關係：** 才考慮 Main Canon。
- **視覺動作明確且能在低成本下表達：** 才製作短劇。
- **觀眾問題有代表性或帶來新證據：** 轉成公開回覆或下一輪研究。

不應要求每個熱門事件產出所有格式。Producer 要比較時效價值、敘事強度、製作成本與角色相關性。
