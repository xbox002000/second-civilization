# 短劇製作系統 v0.1

## 1. 作品角色

短劇是《第二次文明》的敘事產品，不是社群貼文的動態版。它必須讓觀眾看見人物如何在限制中選擇，而不只是聽范蠡講道理。

## 2. 三種短劇來源

1. **主線短劇（Canon）**：改編主線小說，人物與事件受 Canon 約束。
2. **時事映照短劇（Non-Canon）**：從當代事件抽取人性或制度命題，以虛構人物、地點和情節呈現。
3. **角色微劇場（Character Shorts）**：以一個場景建立范蠡的性格、日常、關係、幽默或弱點；不一定依賴新聞。

每支短劇都要在片頭／片尾文案或說明中清楚標示系列屬性，避免觀眾把虛構事件誤認成新聞。

## 3. MVP 時長與節奏

初期先以 45–90 秒直式短劇驗證製作能力。時長不是硬規則；若衝突需要呼吸空間，可另做較長版本。

建議節奏：
- 0–3 秒：視覺鉤子或有張力的問題。
- 3–15 秒：人物、目標與場景關係。
- 15–45 秒：阻力升高，人物必須選擇。
- 45–75 秒：代價、反轉或認知改變。
- 最後數秒：留下一個問題、關係變化或下一集懸念。

不可為了套節奏模板而製造不合理轉折。故事核心優先。

## 4. 劇本最低交付

每集必須包括：
- episode_id、series_id、content_id、Canon 狀態。
- logline、主題命題、觀眾情緒／思考目標。
- 場景、角色、人物目標、阻力、選擇、代價。
- 對白、動作、情緒變化、視聽提示。
- 時間軸、鏡頭／分鏡、字幕和音效需求。
- 角色外觀與聲音連續性參照。
- 圖像、影片、音樂、字型、配音和素材授權清單。
- 需要真人演出或人類決定的項目。
- Reviewer 結果與人工批准紀錄。

## 5. 轉製規則

- Writer 對故事本身負責；Short Drama Director 對影像敘事和可執行分鏡負責；Format Producer 對平台版本、字幕、封面和發布包負責。
- 不得在視覺化時新增會改變事實或 Canon 的關鍵情節。
- 同一角色跨集需有一致造型、年齡感、聲音、服裝狀態和道具連續性。
- AI 生成素材要保存 prompt／參考圖版本、生成工具與人工修改紀錄；不得把尚未確認的素材當成最終 Canon 角色參照。
- 音樂、字型、圖片與影片素材需有可追溯授權；未知授權不得進入正式成片。

## 6. 製作驗收

- 開頭 3 秒能辨識場景問題或視覺變化。
- 觀眾能理解誰想要什麼、什麼阻止他、他做了什麼選擇。
- 故事由人物行動推進，不靠旁白解釋全部。
- 范蠡不是每次都用分析或名言解決衝突。
- 結尾留下情緒、後果或下一步，而不是硬塞「追蹤我」。
- 事實／虛構、Canon／Non-Canon 標記正確。
- 角色連續性、素材授權和人工批准通過。

## 7. MVP 成片路徑

事件研究包／Canon 故事
→ Story Proposal
→ Script Draft
→ Continuity Review
→ Short Drama Director Shot Plan
→ 素材生成／拍攝
→ Rough Cut
→ 視聽與事實審查
→ 人工核准
→ 平台包與發布
→ 成效與觀眾反應復盤。
