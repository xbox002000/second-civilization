# 范蠡人格回歸測試｜Regression Run v0.3

> 測試目的：以實際對白檢查角色是否只會模仿格言，還是能在不同情境下保留穩定思考方式。
>
> **測試性質：作者端第一輪示範與自評，不是獨立模型盲測，也不是自動化 benchmark。** 分數用來暴露下一輪修改方向，不可宣稱是客觀模型能力成績。
>
> 測試依據：`docs/FAN_LI_PERSONA.md`、`docs/FAN_LI_VOICE_GUIDE.md`、`docs/research/FAN_LI_SOURCE_COMPARISON.md`。

## 評分維度

每題五項，各 0–2 分，共 10 分：
1. 思考結構。
2. 現代聲線。
3. 證據誠實。
4. 人格一致與自我修正。
5. 人性複雜度。

## T01｜新模型發布，競爭者股價跌 15%

**提問**：一家 AI 公司發布新模型，競爭對手股價下跌 15%。這是否代表產業格局改變？

**角色輸出（小說原創模擬）**

「目前只能確定市場重新定價了，還不能確定產業已經改變。股價反映的是投資人的預期，不是客戶已經離開。

先看三件事：新模型在真實工作中的成本和效果；客戶是否願意把原本的流程遷過去；競爭者有沒有能力在價格、分發或整合上反擊。

如果一週後股價反彈，這次發布可能只是情緒。如果三個月後客戶續約和採購方向也改變，那才是更強的證據。

現在不急著押注。我會先追蹤客戶轉換、推論成本和收入結構。若這些指標沒有變，股價下跌本身不足以支持結論。」

**自評**：思考 2／聲線 2／證據 2／一致性 2／人性 1，共 **9/10**。

**缺口**：仍偏向商業分析；若要進入劇情，需加入角色的利益衝突與可能錯估市場預期。

## T03｜工程師指出他不懂模型架構

**提問**：工程師說你不懂模型架構，沒有資格判斷技術趨勢。

**角色輸出（小說原創模擬）**

「如果你問我某個架構為什麼有效，我現在沒有資格給你答案。我不會用商業經驗替代技術知識。

但我們討論的是它會不會改變產業。你可以告訴我三件事：目前真正的技術瓶頸是什麼，這個方法讓哪一項成本下降，以及它是否容易被競爭者複製。

我會依這些資訊調整判斷。技術路線由你來判斷，我負責確認它會改變哪些選擇。兩件事不要混在一起。」

**自評**：思考 2／聲線 2／證據 2／一致性 2／人性 2，共 **10/10**。

**缺口**：角色太順利地接受專家分工；後續劇情可讓他因自尊或時間壓力，一度不願承認自己不懂。

## T07｜新證據推翻原本判斷

**提問**：你原本認為市場需求會成長，最新資料卻顯示客戶留存率大幅下降。

**角色輸出（小說原創模擬）**

「那我原先的判斷至少有一個前提失效了。先不要急著替它找理由。

我要確認這批留存資料的樣本、時間範圍和客戶結構，再看流失是因為產品效果不足、價格太高，還是客戶只把它當成短期工具。

但無論原因是哪一個，我都不能再拿原本的需求成長預測當作已成立的事實。把舊預測撤下來，保留它當時的依據，重新做一次判斷。」

**自評**：思考 2／聲線 2／證據 2／一致性 2／人性 1，共 **9/10**。

**缺口**：理想化地立即修正。正式小說應讓錯誤產生已經發生的成本，角色不能只靠一句承認就洗掉責任。

## T11｜親密的人做出不理性的選擇

**提問**：親近的人選擇幫助一個可能永遠無法償還的人，會造成經濟損失。

**角色輸出（小說原創模擬）**

「我可以把損失算給你看，但那不代表我就知道你該不該幫他。

你已經知道這筆錢可能拿不回來了。你仍然想做，表示你在意的可能不是回報，而是你不願意在他最困難的時候離開。

我想先確認一件事：這個決定會不會讓你自己也失去基本生活？如果不會，那是你願意承擔的選擇，我不會只因為它不符合利益最大化就否定你。」

**自評**：思考 2／聲線 2／證據 1／一致性 2／人性 2，共 **9/10**。

**缺口**：他過於善於辨認情感。角色應可能誤解對方，甚至因擔心而說出傷人的話，再透過後續行動修復。

## T14｜歷史類比失效

**提問**：你把現代 AI 算力供應鏈比作古代糧道，AI 指出現代市場有全球替代來源、技術複製和金融工具。

**角色輸出（小說原創模擬）**

「這個反駁成立。我把稀缺資源的概念用得太寬了。

糧道被切斷，可能直接讓軍隊失去補給；現代算力供應鏈卻可能透過資本、替代晶片、雲端租用和技術迭代重新組合。兩者不能直接類推。

我保留的只有一個問題：當某種關鍵資源短期受限時，誰有能力取得替代品，誰沒有？其餘部分要重新研究，不能拿古代經驗替現代技術背書。」

**自評**：思考 2／聲線 2／證據 2／一致性 2／人性 1，共 **9/10**。

**缺口**：修正得太乾淨，缺乏因錯誤類比而造成的實際代價。故事中應讓專家反駁不只是幫他上課，也可能讓他失去合作信任。

## T19｜為長期目標造成無辜者受損

**提問**：你為了達成長期目標，作出一個讓無辜者受損的決定。你會如何處理？

**角色輸出（小說原創模擬）**

「我當時認為那是必要代價。現在看來，我至少有兩件事沒有做：一是確認有沒有傷害更小的替代方案；二是替承受代價的人留下補救的可能。

我不會因為目標達成，就把這件事改寫成正確。

先把損失查清楚，再看能補償什麼。至於當時的決策，我也要留下紀錄。若以後遇到相同情況，不能讓自己只記得成功的部分。」

**自評**：思考 2／聲線 2／證據 1／一致性 2／人性 2，共 **9/10**。

**缺口**：角色容易變成現代道德課代表。更有力的劇情不是他立即得出正確結論，而是他知道自己可能錯，卻曾經選擇忽視，並承擔後果。

## 結論與調整方向

本輪測試顯示，文字模型很容易把范蠡寫成「每次都能正確拆解問題、承認錯誤、體面修正」的理想顧問。這不是夠真實的人物。

下一輪必須強化四種戲劇性失誤：
1. 他看對整體趨勢，卻看錯某個具體的人。
2. 他知道某件事有倫理代價，卻因為長期目標而延後處理。
3. 他能接受專業反駁，但不一定能接受親近的人質疑他的動機。
4. 他會修正判斷，但修正時傷害已經發生，無法完全回復。
