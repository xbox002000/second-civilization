# 第二次文明｜Second Civilization

**以范蠡為公眾人格的 AI 時代敘事 IP：時事觀察、故事宇宙、短劇與社群互動。**

> 核心命題：當 AI 工具逐漸普及，真正拉開差距的，不只是模型能力，而是人如何定義問題、理解系統、驗證判斷並採取行動。

## 我們真正要建立的東西
《第二次文明》不是單純的小說，也不是自動生成貼文的工具。我們要建立一個持續存在的虛構公眾人物——范蠡。他有自己的帳號，觀察主流時事、分析技術與商業變化、提出可被驗證的推論、回答群眾、接受反駁；同時，這些現實觀察會轉化成獨立短篇、主線連載與短劇。

兩個核心：
1. **公眾人格線：** 范蠡如何面對群眾、表達觀點、記住承諾、修正錯誤。
2. **故事宇宙線：** 范蠡轉世到 AI 時代後的人生、關係、選擇與文明命題。

兩條線共享人格和記憶，但現實評論、虛構故事與主線 Canon 必須分層。

## 已確認的故事設定
- 主角歷史身份：范蠡（以歷史人物為原型，內心與轉世經歷屬小說創作）。
- 穿越方式：轉世／reincarnation。
- 現代年齡：年輕。
- 終極追求：真相。
- 核心思想：人人都能使用 AI，但不同的認知結構會帶來不同的使用結果。
- 公眾經營方式：完全沉浸式第一人稱角色。
- 短劇視覺：AI 真人電影感。

未確認的現代姓名、確切年齡、家庭背景、記憶甦醒方式與配角，不得由 Agent 自行寫成正式 Canon。

## 六層系統
| 層 | 功能 |
|---|---|
| L0 角色核心 | 人格、聲線、Canon、角色記憶、公開承諾 |
| L1 現實感知 | 主流時事、來源查核、趨勢與事件資料 |
| L2 范蠡觀局 | 時事評論、事勢推演、公開判斷 |
| L3 事件敘事化 | 時事映照短篇、主線劇情、故事提案 |
| L4 短劇製作 | 劇本、分鏡、視覺素材、剪輯與平台包 |
| L5 公眾關係 | 留言互動、公開更正、預測稽核、角色成長 |

## 內容產品
- **現世觀局：** 范蠡對主流時事提出獨特觀察。
- **事勢推演：** 對技術、商業、制度與社會變化提出有期限的推論。
- **時事映照：** 把真實事件背後的人性與制度衝突寫成非 Canon 短篇。
- **第二次文明：** 長期主線連載。
- **短劇／微電影：** 將主線、時事映照或角色微劇場視覺化。
- **范蠡答眾：** 回應觀眾問題、反駁與新證據。

## 原則
1. 先可驗證，再自動化。
2. FACT / INFERENCE / HYPOTHESIS / FICTION 不可混淆。
3. 主角與 AI 都必須允許犯錯、被反駁與修正。
4. 公開預測保留原始版本，不刪除失敗紀錄。
5. 所有公開發布先經人工核准。
6. 觀眾私人故事未經同意不得改編；不收集不必要的敏感個資。
7. 虛構角色與 AI 輔助創作身份必須對外透明。
8. 流量不能凌駕事實、人物連續性與作品品質。
